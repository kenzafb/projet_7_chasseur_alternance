# Validation des emails trouvés par le scraper (phase 7), sans IA.
# Une valeur par ligne, casse ignorée ; tout ce qui suit un # est un commentaire.
# Les adresses de shared/referentiels/emails_exclus.txt sont écartées avant
# ces règles.
#
# Ordre d'application, pour chaque adresse trouvée sur le site d'une entreprise :
#   1. liste d'exclusion (emails_exclus.txt) ou préfixe écarté : écartée d'office ;
#   2. validée d'office seulement si TOUT est vrai : même domaine que le site de
#      l'entreprise ; ce site a été retenu parce que son domaine correspond au
#      nom de l'entreprise (ni annuaire, ni sous-domaine d'hébergeur, cf.
#      [hebergeurs]) ; le domaine n'est pas un fournisseur générique (cf.
#      [fournisseurs_generiques]) ; préfixe de contact ;
#   3. tout le reste est douteux : l'IA (modèle d'extraction) tranche si elle
#      est active, sinon l'adresse reste « non validée » (jamais envoyée
#      automatiquement, à valider à la main).
#
# Un préfixe vaut pour la partie avant @ entière (« rh@ ») ou suivie d'un
# point, d'un tiret, d'un souligné ou d'un chiffre (« rh.paris@ », « rh-idf@ »,
# « contact2@ »).
